Active Directory PowerShell Administration

Overview

This lab demonstrates how PowerShell can be used to perform common Active Directory administrative tasks. The exercises focused on creating and managing users and security groups, resetting passwords, managing user accounts, and generating reports. Using PowerShell provides a consistent and efficient way to administer Active Directory.

Users Created

The following user accounts were created successfully:

-Alice Smith
-Bob Johnson
-Carol Davis

Security Group Created

-Group Name: IT_Support

-Group Type: Global Security Group

The group was created to organize IT users and simplify permission management.

Group Membership

The newly created users were added to the -IT_Support- security group. Managing permissions through groups is more efficient than assigning permissions to individual users.

Password Management

The password for alice.smith was reset using PowerShell, and the account was configured to require a password change at the next sign-in.

Account Management

PowerShell was used to perform common account management tasks, including:

-Creating user accounts
-Resetting passwords
-Enabling and disabling user accounts
-Verifying user information

Report Generation

A CSV report containing Active Directory user information was generated successfully. Exporting data to a CSV file provides an easy way to review user information, maintain records, and support administrative reporting.


Lessons Learned

During this lab, I gained practical experience using PowerShell to automate Active Directory administration. I learned how to:

* Create Active Directory users.
* Create and manage security groups.
* Add users to security groups.
* Reset user passwords.
* Enable and disable user accounts.
* Search for Active Directory users and groups.
* Export Active Directory information to a CSV report.

This lab demonstrated how PowerShell can simplify repetitive administrative tasks, improve consistency, and make Active Directory management more efficient.
